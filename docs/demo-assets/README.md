# Demo Assets

This directory contains demonstration assets for the Enhanced AI Chat project.

## Screenshots

To create compelling screenshots for your project:

### 1. Main Interface Screenshot
- Take a screenshot of the main chat interface
- Show an active conversation with an AI persona
- Include the sidebar with multiple personas
- Filename: `main-interface.png`

### 2. Persona Creation Screenshot
- Show the persona creation dialog
- Include filled-in example data
- Filename: `persona-creation.png`

### 3. Settings Screenshot
- Display the settings panel
- Show API configuration options
- Filename: `settings-panel.png`

### 4. Mobile Interface Screenshot
- Take screenshots on mobile device or responsive view
- Show mobile-optimized layout
- Filename: `mobile-interface.png`

## Tools for Creating Assets

### Screenshot Tools
- **macOS**: Screenshot (Cmd+Shift+4)
- **Windows**: Snipping Tool or Snip & Sketch
- **Linux**: GNOME Screenshot or Flameshot
- **Browser**: Developer tools device simulation

### GIF Creation Tools
- **LICEcap**: Free, cross-platform
- **GIPHY Capture**: macOS
- **ScreenToGif**: Windows
- **Peek**: Linux
- **Online**: Ezgif.com for editing

### Image Optimization
- **TinyPNG**: Compress PNG images
- **ImageOptim**: macOS image optimization
- **Squoosh**: Web-based image compression

## Best Practices

### Screenshots
- Use consistent browser/device
- Ensure good lighting and contrast
- Include realistic demo data
- Crop to focus on relevant areas
- Use standard resolutions (1920x1080, 1280x720)

### GIFs
- Keep file size under 10MB
- Use 10-15 FPS for smooth playback
- Duration: 3-10 seconds per demo
- Add brief pauses to show results
- Optimize colors to reduce file size

### File Naming
- Use descriptive, lowercase names
- Separate words with hyphens
- Include version numbers if needed
- Example: `main-interface-v1.png`
