## 🔧 安装和配置

### Q: 如何开始使用这个应用？
**A:** 有三种方式：
1. **在线使用**（推荐）：直接访问 [GitHub Pages链接](https://your-username.github.io/enhanced-ai-chat)
2. **本地使用**：下载项目文件，双击 `index.html`
3. **本地服务器**：运行 `python -m http.server 8000` 后访问 `http://localhost:8000`

### Q: 需要安装什么软件吗？
**A:** 不需要。这是一个纯前端应用，只需要现代浏览器即可运行。如果要使用本地Ollama，需要单独安装Ollama。

### Q: 支持哪些浏览器？
**A:** 支持所有现代浏览器：
- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

### Q: 可以离线使用吗？
**A:** 部分可以。界面可以离线使用，但需要网络连接来调用AI API。使用本地Ollama可以实现完全离线。

## 🔑 API配置

### Q: 如何获取火山引擎API密钥？
**A:** 
1. 访问 [火山引擎控制台](https://console.volcengine.com/)
2. 注册并完成实名认证
3. 开通"火山方舟"服务
4. 在API管理中创建密钥
5. 复制密钥到应用设置中

### Q: 火山引擎API收费吗？
**A:** 是的，按使用量收费。新用户通常有免费额度。具体价格请查看火山引擎官网。

### Q: 如何安装和配置Ollama？
**A:** 
```bash
# macOS
brew install ollama

# Linux
curl -fsSL https://ollama.ai/install.sh | sh

# Windows - 下载官方安装包
# https://ollama.ai/download

# 启动服务
ollama serve

# 下载模型
ollama pull llama2
ollama pull qwen:7b
```

### Q: Ollama支持哪些模型？
**A:** 支持多种开源模型：
- Llama 2 (7B, 13B, 70B)
- Qwen (7B, 14B, 72B)
- Mistral (7B)
- CodeLlama (7B, 13B, 34B)
- 更多模型请查看 [Ollama模型库](https://ollama.ai/library)

### Q: 为什么连接Ollama失败？
**A:** 常见原因：
1. Ollama服务未启动：运行 `ollama serve`
2. 端口被占用：检查11434端口
3. 防火墙阻止：允许本地连接
4. 模型未下载：先下载所需模型

## 💾 数据存储

### Q: 我的聊天记录存储在哪里？
**A:** 所有数据存储在浏览器本地的IndexedDB中，不会上传到任何服务器。

### Q: 数据会丢失吗？
**A:** 正常情况下不会。但以下操作会导致数据丢失：
- 清除浏览器数据
- 使用无痕/隐私模式
- 卸载浏览器
- 系统重装

### Q: 如何备份数据？
**A:** 
- 应用会自动备份到LocalStorage
- 即将支持手动导出功能
- 可以使用浏览器的数据导出功能

### Q: 可以在多设备间同步吗？
**A:** 目前不支持。数据仅存储在本地浏览器中。未来版本可能会添加可选的云同步功能。

### Q: 存储空间有限制吗？
**A:** IndexedDB通常支持几GB存储，足够存储数万条对话。具体限制取决于浏览器和设备。

## 🎭 人格管理

### Q: 什么是AI人格？
**A:** AI人格是预设的角色设定，包括性格、背景、说话风格等，让AI扮演不同的角色与你对话。

### Q: 可以创建多少个人格？
**A:** 理论上没有限制，但建议不超过50个以保证性能。

### Q: 如何创建一个好的人格？
**A:** 
1. **明确角色定位**：专家、朋友、助手等
2. **详细背景设定**：年龄、职业、经历
3. **具体说话风格**：正式、幽默、温和等
4. **提供示例对话**：让AI学习风格
5. **测试和调整**：根据效果优化

### Q: 人格之间会相互影响吗？
**A:** 不会。每个人格的对话历史完全独立，不会相互影响。

### Q: 可以分享人格设置吗？
**A:** 目前需要手动复制设置。未来版本将支持人格导入导出功能。

## 💬 聊天功能

### Q: AI为什么回复很慢？
**A:** 可能的原因：
1. 网络延迟
2. API服务器负载高
3. 对话历史过长
4. 模型处理复杂问题

**解决方案**：
- 检查网络连接
- 尝试切换API服务
- 清理部分历史记录
- 简化问题描述

### Q: 如何让AI更好地理解我？
**A:** 
1. **提供上下文**：说明背景信息
2. **具体描述**：避免模糊表达
3. **保持连续**：在同一对话中继续
4. **给出示例**：展示期望的回答风格

### Q: AI忘记了之前说的话怎么办？
**A:** 
1. 检查是否切换了人格
2. 确认对话历史正常保存
3. 避免清除浏览器数据
4. 重新加载页面试试

### Q: 支持哪些指令？
**A:** 当前支持：
- `/persona [名称]` - 切换人格
- `/persona` - 显示所有人格
- 更多指令正在开发中

### Q: 可以发送图片吗？
**A:** 目前不支持图片发送，但在开发计划中。

## 🔧 故障排除

### Q: 页面显示异常怎么办？
**A:** 按顺序尝试：
1. 刷新页面（Ctrl+F5）
2. 清除浏览器缓存
3. 检查网络连接
4. 尝试其他浏览器
5. 查看控制台错误信息

### Q: 消息发送失败怎么办？
**A:** 
1. **检查API配置**：确认密钥正确
2. **测试网络**：访问其他网站
3. **查看错误**：打开浏览器控制台
4. **切换服务**：尝试其他API
5. **重启应用**：刷新页面

### Q: 如何查看错误信息？
**A:** 
1. 按F12打开开发者工具
2. 点击"Console"标签
3. 查看红色错误信息
4. 截图并报告问题

### Q: 应用卡死怎么办？
**A:** 
1. 等待几秒钟
2. 刷新页面
3. 清除浏览器缓存
4. 重启浏览器
5. 检查系统资源

## 🔒 隐私安全

### Q: 我的对话内容安全吗？
**A:** 
- **本地存储**：所有数据仅存储在你的设备上
- **不上传**：除了发送给AI的消息，不会上传任何数据
- **加密传输**：与API的通信使用HTTPS加密
- **无追踪**：不收集用户行为数据

### Q: API密钥会被泄露吗？
**A:** 
- 密钥存储在浏览器本地
- 不会发送到除AI服务外的任何地方
- 建议定期更换密钥
- 不要在公共设备上使用

### Q: 使用Ollama更安全吗？
**A:** 是的。使用本地Ollama时：
- 所有对话完全本地处理
- 不需要网络连接
- 数据不会离开你的设备
- 完全的隐私保护

### Q: 可以删除所有数据吗？
**A:** 可以：
1. 在浏览器设置中清除站点数据
2. 或者清除所有浏览器数据
3. 应用会重置到初始状态
